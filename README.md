# Кабинет кураторов · Кемский округ

Адрес интерфейса: https://mrkustov927-star.github.io/pervye-kem-dashboard/

Этот репозиторий содержит интерфейс и серверные обработчики доступа. Закрытые материалы находятся в приватном KPO2026-2027 и выдаются через Vercel после входа.

Публичная сборка создаётся командой `node scripts/build-public.js`; она не содержит `data.js`, вложений, серверных обработчиков или ключей. Автоматические проверки: `node --test tests/access.test.cjs`.

Для сервера необходимы отдельные переменные `VIEWER_PASSWORD`, `ADMIN_PASSWORD`, `PRIVATE_GITHUB_TOKEN` (Contents: read/write только для KPO2026-2027). Значения вводятся в Vercel, в репозиторий не записываются.

До настройки доступа Vercel к новому хранилищу эта версия находится в ветке `migration/private-curator-access`, рабочая публикация main не переключена.
