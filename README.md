# Первые · Кемский округ

Рабочий адаптивный кабинет для первичных организаций Движения Первых Кемского муниципального округа.

## Публичная часть

- блок ближайших задач и дедлайнов;
- календарь с рубриками «Концепция», «Задача», «Мероприятие», «Отчёт», «Регистрация»;
- акции и проекты;
- быстрые ссылки и документы;
- полнотекстовый поиск;
- фильтры;
- подробные карточки с инструкциями, форматами участия, отчётностью, хештегами, ссылками и файлами;
- журнал последних изменений;
- архив завершённых карточек;
- мобильная нижняя навигация.

## Админ-панель

Адрес: `/admin`.

После входа можно:

- создавать, редактировать, дублировать, скрывать и удалять карточки;
- задавать отдельное отображение каждой даты в календаре;
- управлять форматами участия, отчётностью, ссылками и материалами;
- прикреплять небольшие публичные файлы;
- управлять разделом «Ссылки и документы»;
- редактировать основные заголовки и тексты сайта;
- фильтровать опубликованные, скрытые карточки и черновики;
- видеть, когда изменения реально появились в production на Vercel.

Публикация работает по схеме: админ-панель → GitHub → автоматический production deployment Vercel.

## Файлы

Поддерживаются PDF, Word, Excel, PowerPoint, изображения и архивы до 2,5 МБ на файл.

Файлы сохраняются в публичном репозитории в каталоге `files/`. Поэтому здесь допустимы только публичные материалы без персональных данных: пустые протоколы, положения, макеты, инструкции, формы и шаблоны.

## Данные

Основной контент хранится в `data.js`. Интерфейс сайта читает его через `app.js`. Изменять `data.js` вручную для обычной работы не требуется — контент управляется через админ-панель.

## Безопасность

Для админ-панели используются переменные окружения Vercel:

- `ADMIN_PASSWORD`;
- `GITHUB_TOKEN`.

GitHub token должен иметь доступ только к этому репозиторию и минимальное разрешение `Contents: Read and write`.

Вход имеет ограничение числа неудачных попыток. Раздел `/admin` закрыт от индексации поисковыми системами.

## Фирменный стиль

Используются официальные базовые цвета:

- красный `#D90912`;
- синий `#3366CC`;
- чёрный `#000000`;
- белый `#FFFFFF`.

Используется официальный файл логотипа без перерисовки. В CSS указаны фирменные семейства `Pervye Extended Bold` и `Pervye Book`; webfont-файлы в репозиторий не включены, поэтому на устройствах без установленных фирменных шрифтов используется системный fallback.
