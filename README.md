# Кабинет кураторов · Кемский округ

Основной адрес: https://mrkustov927-star.github.io/pervye-kem-dashboard/

GitHub Pages публикует интерфейс и форму входа. Vercel проверяет отдельные пароли кураторов и администратора. Материалы и вложения находятся в приватном `mrkustov927-star/KPO2026-2027`; API читает их после проверки сессии. Сохранение данных администратором не требует новой сборки интерфейса.

Сборка: `node scripts/build-public.js`. В `public/` нет `data.js`, вложений или серверных обработчиков. Проверки: `node --test tests/access.test.cjs`.

Секреты задаются только в Vercel Production: `VIEWER_PASSWORD`, `ADMIN_PASSWORD`, `PRIVATE_GITHUB_TOKEN` (Contents: read/write только для KPO2026-2027). Значения в репозиторий не записываются. GitHub Pages работает без секретов сборки.

Резервная копия версии до переноса: ветка `backup/before-private-migration-2026-11-22`. Старые опубликованные материалы также остаются в истории репозитория; новые изменения данных и вложения сохраняются в приватном хранилище.
