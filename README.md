# Первые · Кемский округ — dashboard MVP

Рабочий адаптивный дашборд для первичных организаций Движения Первых Кемского муниципального округа.

## Что уже есть

- главная страница «Что нужно сделать сейчас»;
- срочные задачи и ближайшие дедлайны;
- календарь сентябрь–ноябрь 2026;
- раздел «Задачи первичек»;
- раздел «Акции и проекты»;
- документы и быстрые ссылки;
- поиск;
- фильтры;
- карточки с алгоритмом действий, отчётностью, ссылками и хештегами;
- история последних изменений;
- архив;
- мобильная нижняя навигация;
- данные вынесены отдельно в `data.js`, поэтому обновление не требует правок в верстке.

## Источники стартового наполнения

- рекомендации по всероссийским акциям Движения Первых на сентябрь 2026;
- рекомендации по всероссийским акциям Движения Первых на октябрь 2026;
- рабочая переписка чата первичных организаций Кемского района за сентябрь 2026.

## Фирменный стиль

Используются официальные базовые цвета брендбука:

- красный `#D90912`;
- синий `#3366CC`;
- чёрный `#000000`;
- белый `#FFFFFF`.

В CSS первым указан официальный шрифт `Pervye Extended Bold` для заголовков и `Pervye Book` для основного текста. Файлы шрифтов в репозиторий не включены; до подключения официальных webfont браузер использует системный fallback.

Официальный логотип в MVP намеренно не перерисовывается. Его нужно добавить отдельным оригинальным файлом из утверждённого комплекта бренда.

## Публикация

Сайт статический. Его можно публиковать на Vercel без базы данных и без сборки. Позже `data.js` можно заменить API/Supabase, не меняя интерфейс.
