# Аудит рабочего кабинета — 15 ноября 2026 года

Проверены разделение актуальных и завершённых карточек, сроки проектов,
этапы конкурсов, календарь, архив, поиск, ссылки на карточки, мобильная
вёрстка и сохранение календарных этапов через существующую админку.

## Исправления

| Проблема | Результат |
| --- | --- |
| Фильтр «Все» показывал завершённые проекты вместе с актуальными | Основная подборка содержит только текущие и предстоящие материалы. Завершённые доступны в архиве |
| Архив раскрывался на компьютере и восстанавливал сохранённое раскрытие | При новом открытии страницы архив свёрнут. Прямая ссылка на архив или выбор исторического месяца открывает его явно |
| Окончание регистрации принималось за окончание всего конкурса | Срок проекта учитывает последующие этапы. Конкурс первичек, «Приключения Первых» и «Российская школьная весна» остаются актуальными |
| Дата отчёта могла удерживать уже проведённое мероприятие среди актуальных | Мероприятие архивируется по дате проведения; незакрытый срок публикации или отчёта продолжает отображаться в задачах |
| Календарь пропускал отчётные даты при наличии `calendarMap` | Даты отчётности учитываются вместе с регистрациями, мероприятиями и этапами |
| Сведения об этапах находились только в описании | Добавлены 55 этапов/периодов у 9 проектов; они видны в календаре и карточке проекта |
| Период между началом и окончанием не был виден в промежуточном месяце | Под календарём есть список этапов, проходящих в выбранном месяце |
| «Ещё N» в дне календаря не открывало скрытые записи | Дополнительные события раскрываются внутри дня |
| Старые ссылки `?month=2026-10#projects` вели к историческим карточкам среди текущих | Такие ссылки открывают соответствующий месяц архива |
| Сохранение обычной формы админки могло удалить новое поле этапов | Сервер сохраняет существующий массив этапов, если форма его не передала |

## Проверка содержания

- У 5 карточек сохранены ограничения, ранее установленные администратором;
  они не публикуются повторно автоматически.
- На 15 ноября: 9 актуальных акций/проектов и 16 завершённых публичных карточек.
  Задачи и избранное могут пересекаться с этими подборками.
- Сроки конкурса первичных отделений дополнительно сверены с приложенным
  к его карточке положением: п. 6.2, пп. 7.6.17–7.6.23, пп. 9.1–9.2.
- По остальным проектам использованы даты из существующих карточек и их
  материалов. Общие этапы конкурса первичек не заменяют конкретные задания:
  пользователь передаст их после 23 ноября.
- Для финалов, известных только до месяца, точный день не придуман.
  Приблизительные и противоречивые сроки помечены отдельно.

## Проверка работы

- `node --test tests/calendar-lifecycle.test.cjs`: 21 проверка проходит.
- Экспорт в личный календарь использует ближайший действующий срок;
  завершившаяся регистрация не экспортируется вместо следующего этапа.
- Проверены JavaScript, структура HTML, отсутствие повторяющихся ID,
  совместимость преобразования файловых ссылок при сборке GitHub Pages.
- В браузере проверены архив после повторной загрузки, месячные фильтры,
  переход по старой ссылке, календарные этапы, раскрытие дополнительных
  событий и открытие карточки конкурса.
- На экране шириной 390 px архив свёрнут по умолчанию; горизонтальная
  прокрутка страницы отсутствует.

Проверка доступности всех внешних сайтов и действий внутри чужих личных
кабинетов в этот аудит не входила. Черновики и скрытые материалы не раскрыты.
